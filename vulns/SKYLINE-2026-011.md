## Description

The component-accept listener parses XML **before any authentication**, and the
accept-side depth/element limits are hardcoded `0/0` (unlimited) with no operator knob.
The node implementation propagates a dirty flag by walking the **full ancestor chain on
every append** (`judo::Node::_setDirty`, no already-dirty early-exit) — building a
depth-n tree costs Θ(n²) (perf: 91.5% of burn CPU in `_setDirty`; measured ~n^2.4–3).

A 175 KB stream (depth 25,000) costs ~3.3 CPU-seconds solo. **Seven** concurrent
streams on seven distinct names (XCP mio-thread count = 7) saturate **both vCPUs** of
the standard 2-core appliance: measured 440 CPU-s per 231 s wall window on a clone
under load (19× super-additive vs solo-sum; perf-attributed to shared-cache contention
— IPC 0.173→0.071–0.103 — plus 2-core oversubscription; both layers apply to the
production shape). During saturation, new-stream handshake RTT degrades from 0.00–0.03 s
to 12–18 s with 30 s+ timeouts; all XMPP/MRA routing serviced by the daemon stalls.

**Live-verified 2026-10-05 on two real production-version appliances** (single
bracketed volleys): Expressway-E — ΔCPU +218.6 CPU-s ≈ both cores ~90% through a 121 s
degradation window, peak probe 18.18 s, clean recovery, daemon pid continuous;
Expressway-C — ΔCPU +92 CPU-s ≈ both cores ~98% across a 47 s drain, peak 13.09 s,
clean recovery. Drain-driven re-firing sustains saturation **indefinitely** at ~10 KB/s
(clone-verified: 678 s continuous, both cores ~98.5%, service state unrecovered while
loop ran). The daemon never crashes; recovery is immediate when the attacker stops;
zero fail2ban ticks (no jail covers :7400).

## Affected Configuration

Stock X15.5.1 with :7400 reachable by the attacker (default bind: appliance external
interface(s)). No configuration change mitigates — the limits are not exposed.

## Fix

Early-exit `_setDirty` when the ancestor is already dirty (O(1) amortized append);
enforce accept-side depth/element limits with an operator-visible knob; bind :7400 to
loopback (in-process components = zero legitimate external peers); extend IPS jail
coverage to the component port.
