## Description

CUCM 15.x ships with hardcoded credentials in `tomcat-users.xml` that are identical across all installations and cannot be changed by the CUCM administrator. The account has `manager-script`, `manager-gui`, `admin-script`, and `admin-gui` roles, enabling WAR deployment and full Tomcat Manager access. These credentials are actively used by an internal health-check service.

An attacker who reaches the Tomcat Manager — via SKYLINE-2026-001 (X-Forwarded-For bypass) or any SSRF to localhost — can deploy arbitrary WAR files, achieving remote code execution as the `tomcat` service account.

## Affected Configuration

```xml
<user username="1mJdd4WKi+" password="1ge1AVWsx~"
      roles="manager-gui,manager-script,admin-gui,admin-script"/>
```

## Fix

Remove hardcoded credentials. Implement a per-installation credential generation mechanism during CUCM setup, or disable the Tomcat Manager application entirely if not required.
