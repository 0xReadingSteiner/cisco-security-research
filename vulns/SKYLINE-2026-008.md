## Description

The rebuild parses `Content-Length` with an unchecked 64-bit accumulator modulo 2⁶⁴: `Content-Length: 18446744073709551616` (2⁶⁴) wraps to **0** — the connection stays alive and the next byte on the wire leaks into a fresh request line (desync oracle: a leaked `X` produces an `XGET`-style 403/400 signature distinct from honest framing); `2⁶⁴+1` wraps to **1** and processes byte-identically to an honest `Content-Length: 1`. Upstream fixed this in `a9ec41a35`, public since 2026-07-28 — eleven weeks before this Cisco build shipped; the fork additionally lags upstream ~4 releases / ~100 CVEs.

**Full backend-leg delivery demonstrated live** (2026-09-23) on the internet-facing edge and on a configuration-identical clone: a `CL=2⁶⁴` POST with a body-hidden GET desynchronized the connection so the hidden request became an independent transaction, which the remap chain routed to a **plugin-free loopback backend rule** and served — the backend's own access log recorded the smuggled GET with its marker URL at 200, and the second response arrived on the attacker's socket. Honest-CL negative control: the identical hidden request was consumed as inert body. This converts the edge into a request forger against backend origins that the front-door plugin chain never exposes.

Security impact: request smuggling at the transaction layer (frontends/chained proxies disagreeing on message boundaries), backend-leg request forgery where any ungated remap rule exists (deployment-conditional — the demonstrated anchor was the plugin-free statics rule), and a reliable pre-auth desync oracle for probing edge behavior. Zero fail2ban ticks on the demonstrated paths.

## Affected Code

`mime_parse_int64` (ATS 9.2.11 Cisco rebuild): unchecked accumulate; no `Content-Length ≤ INT64_MAX` validation, no rejection of wrap-consistent values. Fix `a9ec41a35` adds the range check.

## Fix

1. Ship upstream `a9ec41a35` in the next rebuild; reject out-of-range `Content-Length` with 400 and close.
2. Audit remap rules for plugin-free backend legs reachable from the catch-all (the demonstrated anchor); gate or remove them.
3. Detection: see False;Relay mitigations.md §1.2 (`Content-Length` ≥ 20 digits + stream-desync anomaly events).
