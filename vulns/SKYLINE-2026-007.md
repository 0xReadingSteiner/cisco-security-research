## Description

The shipped ATS rebuild accepts CR/LF sequences inside an **unterminated quoted-string chunk extension** — the exact defect upstream fixed with persistent `in_quoted_string`/`in_escape` parser state. Using Apache's own gold-test payload shape (`chunk_extension_client.py`): a POST with `Transfer-Encoding: chunked`, body `1;a="<CR><LF>X<CR><LF>0<CR><LF><CR><LF>`, followed by an embedded GET, produced **two responses on one send** — including the embedded request's 200 with expected content magic bytes. Patched ATS rejects this with 400 (`CHUNK_READ_ERROR`). Cross-buffer inconsistency confirmed: splitting the payload after `1;a="` across a 300ms delay changes the outcome (quoted-string state not preserved across reads).

Honest scope, live-verified on this deployment: embedded requests are processed as **full ATS transactions** — remap and the complete plugin chain (`ts_auth` included) re-apply — so on a standalone Expressway this is *not* an authentication bypass. The security impact is **parser differential**: any stricter frontend (WAF, load balancer, chained proxy) or raw-parsing backend sees body bytes where the edge sees an independent request. Signature engines and policy filters chained in front of the MRA edge are blind to the hidden request; client tooling never shows it. In the False;Relay context this is the edge-amplifier layer: the same :8443 listener that carries the corridor also smuggles past whatever inspection the defender chained in front of it.

Confirmed live pre-auth on Expressway X15.5.1, 2026-09-18: accept-and-forward on the malformed extension; honest well-formed controls behave identically at the transaction layer (proving the desync, not pipelining, is the discriminator); zero fail2ban ticks (all responses 2xx).

## Affected Code

Upstream fix `e44213f8ec` (2026-06-26) adds persistent quoted-string/escape state to the chunk decoder; the 2026-05-08 Cisco build predates it. Binary and wire behavior both confirm the pre-fix shape.

## Fix

1. Ship the upstream fix (`e44213f8ec`) in the next Expressway ATS rebuild; reject unterminated quoted-string extensions with 400.
2. Until patched: terminate TLS at a strict, fully-patched HTTP frontend in front of :8443 and re-originate connections to the edge (removes the parser differential).
3. Detection: see False;Relay mitigations.md §1.3 (chunk-extension shape + multi-transaction-per-flow alerting).
